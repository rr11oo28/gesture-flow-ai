# Gesture Flow AI

## Kompyuterda
    npm install
    npm run dev          ->  http://localhost:5173

## Telefonda (2 yoʻl)
1) Bir xil Wi-Fi: `npm run phone` -> terminalda chiqqan `https://192.168.x.x:5173` manzilni telefonda oching
   (sertifikat ogohlantirishida "Davom etish" ni bosing; kamera faqat HTTPS bilan ishlaydi).
2) Ochiq havola: `npm run build`, soʻng `dist` papkasini https://app.netlify.com/drop ga tashlang
   (yoki `npx vercel`). Tayyor HTTPS havola telefonda ham, kompyuterda ham ishlaydi.

Klavishlar: ←/→ boʻlimlar, ↑/↓ skroll, Probel rejim, M ovoz, C kamera, T kuzatuv.
